Code Exercise: Load Balancing Algorithm

In this architectural challenge, you must implement a simple round-robin load balancer to distribute incoming traffic across a cluster of three servers.

Task Requirements

  • Create a function distributeLoad(requests).
  • Requests should be assigned sequentially to Server A, Server B, and Server C.
  • The function should return an array of objects mapping Request ID to Server Name.

Input Format

An array of integers representing request IDs, e.g., [101, 102, 103, 104].

Expected Output

[

  { "requestId": 102, "server": "B" },
  { "requestId": 103, "server": "C" },
